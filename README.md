# TaskFlow

O TaskFlow é um aplicativo desenvolvido para ajudar na organização e no gerenciamento de tarefas do dia a dia.

Com ele, é possível

- Cadastrar novas tarefas.
- Visualizar a lista de tarefas.
- Marcar tarefas como concluídas ou pendentes.
- Filtrar tarefas por status.
- Consultar os detalhes de cada tarefa.
- Editar tarefas cadastradas.
- Excluir tarefas.
- Salvar as tarefas para que continuem disponíveis ao abrir o aplicativo novamente.

O objetivo do TaskFlow é facilitar a organização das atividades, tornando o acompanhamento das tarefas mais simples e prático.
